Editable GitHub Website
Click text to edit, click images to replace, publish when ready
This site works as a static GitHub Pages file. You can edit directly on the page, then either download the updated index.html or publish it straight to your GitHub repository from here. For GitHub publishing, a fine-grained personal access token with Contents: write permission for this repository is needed. GitHub publishing uses a fine-grained token with repository contents write access and updates the file directly in your repository.
